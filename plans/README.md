### Conventions that apply to every plan

- **`plans/` is untracked.** An unscoped `git status` will always show `?? plans/`.
  When a plan's done-criteria check "only files X,Y were modified", they use the
  scoped form `git status --porcelain -- X Y` — do not try to "clean" the untracked
  `plans/` dir, and note that updating this `plans/README.md` status row is the one
  expected write outside each plan's in-scope source list.
- **PyYAML is optional.** Several plans verify CI YAML with
  `python3 -c "import yaml; yaml.safe_load(...)"`. If that import raises
  `ModuleNotFoundError`, PyYAML is not installed — skip the check and rely on CI to
  reject malformed YAML on push. Never treat a missing-PyYAML error as a failure.
